# Changelog

All notable changes to Releases are documented here.

## [0.1.1] - 2026-09-22

### Security

- Escape HTML attributes, restrict release-state classes and only link to EpicEncore's HTTPS GitHub Release URLs.
- Move the catalogue script into a local file so the CSP no longer permits inline JavaScript.

### Fixed

- Label release-page placeholders accurately and allow the existing Google Fonts stylesheet and font resources in the CSP.
- Wrap long checksums within narrow download cards to prevent horizontal overflow on phones.

## [0.1.0] - 2026-09-21

### Added

- Added portable EpicEncore project instructions, versioning, and release safeguards.
